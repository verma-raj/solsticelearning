# Reset your Solstice password (self-service)

If you forgot your Solstice Learning password, you can reset it yourself in a few minutes.

1. Go to the Solstice sign-in page (or open Solstice Desktop for Windows) and select **Forgot password?**
2. Enter the work email address linked to your account.
3. Open the email titled "Reset your Solstice password". It is sent from no-reply@solsticelearning.example.
4. Select **Choose a new password** and enter a password that meets the password requirements.

The reset link is valid for **30 minutes** and can be used **once**. If it expires, request a new one. You can request a maximum of **3 reset emails per hour** per account.
