# Personal data in exports

By default, exports leave out learners' personal data fields such as phone number and email address, which are replaced by a learner ID.

To include them, an Account Owner must grant the **Export PII** permission to a user under Admin Console > Roles. Every export that includes personal data is recorded in the audit log.
