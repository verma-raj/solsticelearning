# Resetting your password in Solstice Desktop for Windows

Solstice Desktop for Windows (version 4.2 or later, on Windows 10 21H2 or later and Windows 11) uses the same Solstice account password as the web app.

To reset it:

1. On the Solstice Desktop sign-in screen, select **Forgot password?** Your default browser opens the reset page.
2. Complete the reset using the link emailed to you (see "Reset your Solstice password").
3. Return to Solstice Desktop and sign in with the new password.

**If the app keeps using your old password:** Solstice Desktop stores a sign-in token in Windows Credential Manager. Open Control Panel > Credential Manager > Windows Credentials, remove the entry named **SolsticeDesktop**, then restart the app and sign in again.
