# Adding or removing seats mid-cycle

Subscriptions are priced per seat (an active learner).

- **Adding seats:** new seats take effect immediately and are charged for the remaining days in the current cycle (prorated daily). The charge is made straight away.
- **Removing seats:** the reduction takes effect at the **start of the next billing cycle**. There is no refund or credit for the current cycle.

Seat counts can be changed by an Account Owner or Billing Admin under Admin Console > Billing > Seats.
