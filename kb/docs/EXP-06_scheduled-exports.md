# Scheduled exports

Scheduled exports run a saved report automatically on a **daily, weekly or monthly** basis and email a download link to the recipients you choose.

- Maximum of **20 scheduled exports** per organization (100 on Enterprise).
- Scheduled exports follow the same row limits as bulk exports.
- Delivery to an SFTP server is available on the **Enterprise** plan only.
