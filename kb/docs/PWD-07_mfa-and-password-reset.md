# Multi-factor authentication and password resets

Resetting your password does **not** remove or change multi-factor authentication (MFA).

If you lost the device you use for MFA, an admin must reset it: Admin Console > Users > select the user > **Reset MFA**. The user enrolls a new device the next time they sign in.

When you first enable MFA you are given **10 one-time backup codes**. Each code works once. Store them somewhere safe, because they let you sign in without your device.
