# How an admin resets a learner's password

Administrators with the **User Admin** role (or higher) can trigger a password reset for any learner in their organization.

1. Open Admin Console > **Users**.
2. Select the learner.
3. Choose **Actions > Send password reset email**.

The learner receives the standard reset email, and the link is valid for 30 minutes. Admins can never view, choose or set a learner's password. When the learner completes the reset, all of their active sessions are signed out.
