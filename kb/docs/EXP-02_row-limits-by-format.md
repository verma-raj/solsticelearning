# Row limits by format (instant exports)

Instant exports are limited by file format:

| Format | Maximum rows per instant export |
|---|---|
| CSV | 50,000 |
| XLSX | 25,000 |
| PDF | 5,000 |

If your report has more rows than the limit, the export is stopped and you are prompted to use a **bulk export** (CSV only) or to narrow your filters.
