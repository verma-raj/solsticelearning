# Help! My password reset email never showed up

Didn't get the reset email? Here's the quick checklist:

- Give it **5 minutes**. Sometimes it's slow.
- Look in spam / junk. The sender is no-reply@solsticelearning.example.
- Double-check you typed the same work email that's on your Solstice account.
- Ask your IT team to allow-list the domain solsticelearning.example.
- Remember we only send **3 reset emails per hour**, so spamming the button won't help.

Still nothing? Ask an admin to check which email address is on your user record in Admin Console > Users.
